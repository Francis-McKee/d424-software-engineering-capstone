# Internal Appointment Scheduling System

## Overview

A React and Firebase web application used to internally manage client appointments.

## Technology Stack

- React
- Vite
- Firebase Authentication
- Firestore Database
- Firebase Hosting
- GitHub Actions

## Installation
`npm install`

## Run Locally
`npm run dev`

## Build
`npm run build`

## Deploy
`firebase deploy`
